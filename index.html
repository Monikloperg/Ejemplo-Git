¿Qué es Git y GitHub?

Control de versiones y colaboración en el desarrollo de software

Herramienta

Git

Git es un sistema de control de versiones distribuido. Registra los cambios que se hacen en los archivos de un proyecto, de modo que puedas volver a cualquier versión anterior, comparar cambios y trabajar en paralelo sin pisar el trabajo de otros.

  • Funciona localmente, en tu propio computador.
  • Guarda el historial completo del proyecto.
  • Permite crear ramas para probar ideas sin afectar el código principal.
  • Es gratuito y de código abierto (creado por Linus Torvalds en 2005).
Plataforma

GitHub

GitHub es un servicio en la nube que aloja repositorios Git. Permite compartir el código, colaborar con otras personas y gestionar proyectos desde el navegador.

  • Almacena tus repositorios en línea como copia de seguridad.
  • Pull requests para revisar y aprobar cambios.
  • Issues para reportar errores y planear tareas.
  • Herramientas extra: GitHub Actions, GitHub Pages, control de permisos.

Flujo de trabajo básico

Modificar archivos→ git add→ git commit→ git push→ Pull request en GitHub

Comandos esenciales

git init                     # crea un repositorio nuevo
git status                   # muestra el estado de los archivos
git add .                    # prepara todos los cambios
git commit -m "mensaje"      # guarda los cambios en el historial
git branch nueva-rama        # crea una rama
git switch nueva-rama        # cambia de rama
git remote add origin <url>  # conecta con el repositorio en GitHub
git push -u origin nueva-rama  # sube la rama a GitHub
